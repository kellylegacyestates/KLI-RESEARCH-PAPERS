## Research Integrity

**Assertion → Authority → Verification → Qualification → Citation**

Primary authority is preferred where reasonably available.

AI-generated output is not authority and must be independently verified before supporting a material institutional proposition.

## Version Discipline

Issued versions are immutable historical records.

A material correction receives a new version.

Example:

v1.0 → v1.1

Silent substantive replacement is prohibited.
