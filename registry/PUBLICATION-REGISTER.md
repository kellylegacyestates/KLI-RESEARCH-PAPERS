## Registry Rule

Every issued KLI Research Paper Series publication must identify:

- Document ID
- Title
- Author
- Version
- Publication status
- Publication date
- Verification status
- Current, superseded, withdrawn, or archived disposition

A file is not treated as an institutional issue merely because it exists in the repository.
